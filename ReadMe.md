# 🕒 Sistem Informasi Absensi Berbasis Web

Sistem absensi sederhana namun fungsional yang dibangun menggunakan **PHP Native** dan **MySQL**. Proyek ini dirancang untuk memudahkan pencatatan kehadiran karyawan/siswa secara digital.



## 🚀 Fitur Utama
- **Multi-user Login:** Mendukung role Admin dan Karyawan/Siswa.
- **Real-time Attendance:** Mencatat jam masuk dan jam pulang secara otomatis.
- **Admin Dashboard:** Fitur untuk memantau seluruh kehadiran dan menambah user baru.
- **Responsive UI:** Menggunakan Bootstrap 5 agar nyaman dibuka di HP maupun laptop.

## 🛠️ Teknologi yang Digunakan
- **Bahasa:** PHP
- **Database:** MySQL
- **Desain:** Bootstrap 5 (CSS Framework)
- **Server:** XAMPP (Apache)

## 📋 Cara Instalasi di Lokal (XAMPP)
1. Download/Clone repository ini dan masukkan ke folder `C:/xampp/htdocs/absensi`.
2. Nyalakan **Apache** dan **MySQL** di XAMPP Control Panel.
3. Buka `phpMyAdmin` (localhost/phpmyadmin), buat database baru bernama `db_absensi`.
4. Import file `database.sql` ke dalam database tersebut.
5. Akses website melalui browser di alamat `localhost/absensi`.
